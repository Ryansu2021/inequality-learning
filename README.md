# 不等式學習｜門檻：情境不等式

國中數學「一元一次不等式」情境應用的互動網頁。針對學生在 111–115 會考中常見的困難——讀不完長資訊、找不到不等關係、單位沒對齊——設計五個出口與一個評量：

| 出口 | 名稱 | 練什麼 |
|---|---|---|
| 1 | 語詞 | 讀中文語句，決定方向與邊界（實心／空心） |
| 2 | 單位 | 單位消去，對齊單位（附配音示範影片） |
| 3 | 臨界點 | 比較兩方案，先找一樣多，再判斷哪一側 |
| 4 | 取整 | 畫出解、逐一試數，往解的一側取整數／概數 |
| 5 | 讀題 | 圈問的量、畫條件語詞、對齊單位、列式、作答 |
| 評 | 評量 | 8 題不給提示，交卷後看各出口掌握度與逐題解析 |

另有白板功能（右上角「白板」），可在螢幕上計算或講解。

單一 HTML 檔，固定 16:9 自動縮放，可離線使用。
